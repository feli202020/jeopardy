# Eigene Sounds

Lege hier MP3-Dateien ab, um die eingebauten synthetischen Töne zu ersetzen.
Erkannte Dateinamen:

- `lobby.mp3`   — läuft in der Lobby (Display), wird automatisch wiederholt
- `buzz.mp3`    — wenn jemand buzzert
- `correct.mp3` — richtige Antwort
- `wrong.mp3`   — falsche Antwort
- `think.mp3`   — während der Timer läuft

Ohne diese Dateien erzeugt das Spiel eigene Töne per Web Audio API —
es funktioniert also auch ohne Downloads.

**Hinweis zum Urheberrecht:** Das originale Jeopardy-Thema ("Think!") ist
urheberrechtlich geschützt. Für den privaten Spieleabend ist das in der Regel
unproblematisch, eine Veröffentlichung damit aber nicht.
